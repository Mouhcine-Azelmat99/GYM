# Forma design system

Reference: dashboard-concept.png, generated for this project. Working brand: Forma.

Inter, locally hosted. Cool gray #f8fafc canvas, white surfaces, #18181b primary text and buttons, #64748b supporting text, #dc2626 danger. Borders #e2e8f0. Use 10px panel corners, 7px controls, 24px panel padding and 24px page gaps. Sidebar 232px; toolbar 72px. Main heading 32px, panel titles 17px, body 14px, supporting labels 12px. Lucide outline icons, 18px and 1.8 stroke. Tables and schedule lists share horizontal separators. Neutral secondary actions. Native HTML forms, accessible dialogs, visible focus and reduced motion support.

Functional extensions: shared shell for members, plans, schedule, attendance, payments, team and settings. Member portal reuses the same typography and panels. All sample statistics derive from demo records. Dates follow current gym timezone; exact demo figures may differ from the illustrative concept. Responsive navigation becomes a horizontal strip on small screens; tables scroll inside their panels.
